# User stories — ChaseFlow Invoices

## Activation
- As a new user I can sign up and import or create my first invoice quickly
- As a user I can launch a chase sequence and see status

## Core loop
- As an operator I can create invoices and attach payment links
- As an operator I can start multi-channel polite follow-ups
- As an operator I can see cash-flow forecast from outstanding receivables
- As an admin I can unlock full access with the owner code
