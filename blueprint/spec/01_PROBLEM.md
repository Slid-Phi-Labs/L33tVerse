# Problem frame — Operator Dashboard

## Problem statement
Operators of Agent-Rider / multi-agent systems lack a single pane of glass for health, alerts, and control-plane status. They stitch together logs, dashboards, and Slack noise and still miss failures.

## Who hurts most
- Operators already running Agent-Rider or similar agent fleets
- Platform engineers responsible for uptime of agent systems

## Why now
Agent fleets are growing; health signals exist but are fragmented.

## MVP job-to-be-done
See live health of the agent control plane and receive clear alerts in one place.
